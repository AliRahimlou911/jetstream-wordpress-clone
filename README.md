# Jetstream Vacations: WordPress version

A WordPress rebuild of the Jetstream Vacations site, with the same pages, design, forms and interactions, plus an organised admin.

**Live site (static, Netlify):** https://jetstream-vacations-wp.netlify.app

**WordPress demo with admin:** [open in WordPress Playground](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/AliRahimlou911/jetstream-wordpress-clone/main/blueprint.json). It boots a temporary copy in your browser. The admin is at /wp-admin, with user `admin` and password `password`.

- `jetstream-theme.zip`: upload in Appearance > Themes > Add New > Upload Theme. Activating it creates all pages, menus, content and images.
- `jetstream/`: theme source
- `HOW-TO-EDIT.md`: install, migration and editing guide
